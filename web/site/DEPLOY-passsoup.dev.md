# Как выложить сайт на passsoup.dev (домен на Cloudflare)

У тебя домен в Cloudflare — это самый простой случай. Сайт = 2 файла
(`index.html`, `verify.html`) в одной папке. Ниже — по шагам, без терминов.

## Способ 1 — Cloudflare Pages, загрузка папкой (5 минут, рекомендую)

1. Положи `index.html` и `verify.html` в одну папку, например `soup-site`.
2. Зайди на **dash.cloudflare.com** → в левом меню **Workers & Pages**.
3. Нажми **Create** → вкладка **Pages** → **Upload assets** (загрузить файлы).
4. Дай проекту имя, например `soup`. **Перетащи папку `soup-site`** в окно → **Deploy**.
5. Через ~20 секунд Cloudflare даст адрес вида `soup.pages.dev`. Открой — проверь, что сайт работает.
6. Привязка домена: в проекте открой вкладку **Custom domains** → **Set up a custom domain**
   → впиши **`passsoup.dev`** → **Continue** → **Activate domain**.
   Так как домен уже в Cloudflare, DNS-запись создастся **автоматически**, HTTPS тоже.
7. Через 1–5 минут `https://passsoup.dev` откроет твой сайт. Готово.

> Хочешь ещё и `www.passsoup.dev` — повтори шаг 6 с `www.passsoup.dev`.

## Обновить сайт потом

Когда я пришлю новые файлы — в том же проекте Pages нажми **Create deployment** →
снова перетащи папку. Старый адрес сохранится.

## Способ 2 — через GitHub (если захочешь автообновление)

Файлы уже лежат в репозитории в папке `web/site/`. В Cloudflare Pages можно выбрать
**Connect to Git** вместо загрузки папки, указать репозиторий `passsoup/Soup`, а в
настройках сборки: **Build command** — пусто, **Build output directory** — `web/site`.
Тогда сайт будет сам обновляться при каждом коммите. Это чуть сложнее — если не нужно,
пользуйся Способом 1.

  правило: `rafik@passsoup.dev` → твоя реальная почта. Бесплатно.
- **Переключатель языка** (РУ/EN) и тёмная/светлая тема — уже встроены, работают сами,
  запоминают выбор пользователя.
